Kokoro model files for the spike. Not committed (see ../../../../.gitignore).

Run `ios/KokoroSpike/setup.sh` to download:

- `kokoro-v1_0.safetensors` (327 MB): Kokoro-82M v1.0 weights, Apache-2.0 (hexgrad/Kokoro-82M).
- `voices.npz` (14.6 MB): the 28 English voice packs (20 US, 8 GB), Apache-2.0.

Both come from mlalma/KokoroTestApp (Git LFS), the files kokoro-ios is tested with.
